শখের ঝুড়ি — Minimal Fashion Store (Starter)
ফাইল: index.html

চালানো:
1. index.html ব্রাউজারে খুলুন অথবা GitHub repository-তে আপলোড করে GitHub Pages চালু করুন।
2. ডেমোতে পণ্য যোগ, cart, checkout এবং order localStorage-এ সংরক্ষিত হয়।
3. Admin খুলতে footer-এর Admin লিংক; demo PIN 1234।

গুরুত্বপূর্ণ:
এটি একটি frontend starter/demo। localStorage-এর অর্ডার শুধু একই ব্রাউজার/ডিভাইসে থাকে; মালিকের কাছে যায় না।
লাইভ করার আগে Firebase Authentication + Firestore/Storage, নিরাপদ admin role/rules, server-side order handling, আসল ফোন/সোশ্যাল লিংক, পণ্যের ছবি/দাম/স্টক, এবং payment gateway/merchant account যোগ করতে হবে।
ডেমো PIN 1234 নিরাপদ নয়; production-এ ব্যবহার করবেন না।
Google Fonts ও Unsplash ছবি লোডে ইন্টারনেট প্রয়োজন।
